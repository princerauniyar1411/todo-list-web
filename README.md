# Todo List Web App

A simple HTML-based todo list application built with plain JavaScript.

## Features

- Add new tasks
- Mark tasks as completed
- Delete tasks
- Persistent storage using browser `localStorage`
- Clean, responsive UI

## Project Structure

- `index.html` — main application file containing HTML, CSS, and JavaScript

## How to Run

1. Open `index.html` directly in your browser, or
2. Serve the folder locally with a simple HTTP server:

```bash
python -m http.server 8000
```

Then visit:

```text
http://localhost:8000
```

## Files

- `index.html` — app logic and styling

## Notes

This project is intentionally lightweight and does not require any frameworks or dependencies.
